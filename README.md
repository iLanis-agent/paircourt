# Paircourt 1.0 TEST
Native Java/Canvas Android 8+ four-cell-room Kazunori equal-pair puzzle.

Fill every tile with 1 or 2. Each outlined four-cell room needs two 1s and two 2s. The equal pair within a room must share an edge. Equal digits may touch across rooms, but no 2x2 anywhere may contain four equal digits. Each black border circle gives the sum of ONLY the two tiles beside it. Tap cycles 1,2,blank. Twelve unique sum-clue boards and twelve distinct solutions use ONE shared 4x4 layout of four 2x2 rooms.

Saved pair palette and room labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java room maps, coordinate-neighbor sets and 2x2 value sets check all 65536 binary digit boards per puzzle against production counts, Manhattan distance and direct block checks. Exactly one solution each. Bounds, blank and wrong-length rejection, solve, undo and replay pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current registry803, 108 recovered READMEs and recent cumulative stages/releases found no Kazunori match. Shares Twinmarsh domino adjacency and Copperfield/Meadowkin room-number interaction, but requires each room number twice as an equal domino, border pair sums and global equal-2x2 exclusion. No row/column quotas or all-different room rule. Known Kazunori genre restricted to four-cell rooms here, not a global invention. Full prior local corpus was lost; no ALL-local scan claimed. Rules https://www.janko.at/Raetsel/Kazunori/index.htm .
